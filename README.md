# Myanmar-AI-Assistant-
Local AI assistant for Myanmar and secure privacy

## 💻 Technology
- HTML5, CSS3, JavaScript
- PWA (Progressive Web App)
- Free Real APIs
- Myanmar Language Support
- Responsive Design

## 📱 Installation
1. GitHub Pages မှာ ဝင်သုံးပါ
2. Browser menu ကနေ "Add to Home Screen" နှိပ်ပါ
3. App အဖြစ် သုံးလို့ရပါပြီ

## 🔧 APIs Used
- OpenWeatherMap - ရာသီဥတု
- ExchangeRate-API - ငွေလဲနှုန်း
- Official Joke API - ဟာသများ
- Quotable API - စကားစုများ
- NewsData.io - သတင်းများ
